# Faculty authoring: how it works

1. Open **Report queue**, choose a defect case and select **Author a fix**. Closed/deferred cases must first be reopened.
2. Tick the field(s) you intend to change. The available fields depend on repair type. For missing/duplicate options, edit the question HTML; for a missing figure, upload a PNG/JPEG under 150 KB or draw a simple figure; for a type mismatch, choose the new type and supply the correctly shaped answer. Chapter cases allow chapter text. Unsound/mismatched questions can require question, solution and answer together. Syllabus reviews remain a review-without-fix decision.
3. Provide the reviewer name and rationale, explicitly attest to your review and permission to use materials, and for diagram addition/replacement describe the source or original authorship. This is a reviewer declaration, not independent verification. Choose **Preview changes**, inspect before and after, and **Confirm & save preview**. The preview is temporary and expires after 15 minutes or a restart. If data changes, start again.
4. The case closes and **Audit history** records author, rationale and complete before/after values. Existing source JSON stays untouched; changes only affect this workspace's persisted copy. Reopen a case to continue review. Diagrams can be added, replaced or removed by their one-based list position. External image references are not loaded in the console, so confirm their identity separately before replacing or removing them.

A reviewer is self-declared, not authenticated as actual faculty. Structural validation checks bounds, scope, active content, answer shape/options, stale state and supported raster formats; it does not prove subject accuracy, source rights or compatibility with Acadza's production schema. An uploaded or drawn figure must be checked and authorised by the reviewer. No AI-generated content or faculty-only repair is auto-applied through this workflow.

The sample-specific mathematical guard rejects certain conflicting answer-key changes for unchanged stems in R001–R005, R016 and R034. It does not check all questions or establish accuracy, and does not apply once the stem is modified.
